# Meridian — Estate

A photoreal walkthrough experience for a concept residence, path-traced in Blender Cycles.

- `index.html` — the guided scroll tour
- `walk.html` — free-roam walk mode (WASD / drag-to-look / click-to-navigate)

Once GitHub Pages is enabled for this repo (Settings → Pages → Deploy from branch → `main` / root), the site will be live at:

`https://leons45.github.io/Estate/`
